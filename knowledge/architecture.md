# 系统架构

系统由文档层、索引层、检索层、回答层和界面层组成。文档层支持 TXT、Markdown 和可提取文本的 PDF。扫描版 PDF 无文本时会明确提示需要 OCR。

索引层使用字符二至四元组 TF-IDF 生成本地向量，并归一化为单位长度。优先通过 FAISS IndexFlatIP 计算内积；若 FAISS 不可用，就使用 NumPy 精确余弦检索作为后备。

索引保存在 data/index 目录，其中 meta.json 保存来源元数据，vectorizer.pkl 保存向量器，vectors.npy 保存向量。重启后可以直接加载，不需要重复分块和向量化。

# 混合检索

自主改进采用混合检索：向量相似度占 72%，关键词覆盖率占 28%。系统先召回十二个候选块，再重新排序并返回前三条证据。
